# REA analysis targets

This directory is the dedicated `REA_ANALYSIS_ROOT` for the optional REA MCP service. It contains only the small, benign `demo-app` fixture by default. Place only applications or artifacts you own or are authorized to inspect here; never execute unknown targets. Files on a free Render filesystem are ephemeral and are not an upload/storage API, so production targets must be provisioned deliberately and the root path must match ULTRON's configuration.
