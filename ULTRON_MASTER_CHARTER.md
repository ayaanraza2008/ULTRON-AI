## 2. THE 12 IMMUTABLE LAWS OF ULTRON ENGINEERING

Every AI agent, engineer, and process operating on this repository must strictly adhere to these 12 laws:

1. **Continue From Actual State:** Always inspect `git status`, latest commit, and `ULTRON_CHECKPOINT.md` before making any modifications. Never guess repository state.
2. **Never Restart From Scratch:** Every feature must be built incrementally on top of the existing codebase. Never discard working systems.
3. **Never Replace Architecture With Demos:** Disconnected demonstrations, hardcoded UI mocks, and dummy scripts are strictly prohibited. Production code must execute real logic.
4. **Preserve User Data & History:** Existing database records, conversations, memories, preferences, and documents must be preserved and safely migrated.
5. **Reuse Existing Implementations:** Leverage existing battle-tested modules (`agent-runtime.js`, `brain-router.js`, `orchestrator.js`, `kokoro-engine.js`, `robot-controller.js`, etc.) instead of recreating duplicates.
6. **Strict Project Isolation:** Never modify or interfere with PHANTOM, NOX, VAULTAR or any external projects.
7. **Strict Render Destination:** Never deploy to any workspace other than **`Ultron core`**.
8. **Zero Secret Leakage:** Never hardcode API keys, service roles, or credentials in code or commit history. Pass credentials strictly through environment variables.
9. **No Mock-Only Shortcuts:** Tests may use mock transports to test error handling deterministically, but production runtime engines must never be replaced by mocks.
10. **Maintain Backward Compatibility:** Ensure existing API routes, worker contracts, and database schemas continue functioning without breaking changes.
11. **Approval for Destructive Actions:** Never perform irreversible file deletions, production database flushes, financial transactions, or unverified physical actuator motions without explicit operator authorization.
12. **Verification Before Completion:** Never claim a task, capability, or bug fix is complete without passing automated test evidence (`node --test`) and syntax verification (`npm run check`).
