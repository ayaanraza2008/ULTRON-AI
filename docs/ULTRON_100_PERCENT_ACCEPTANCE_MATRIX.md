## Status vocabulary

Use only these statuses:

- **NOT STARTED** — no implementation evidence identified.
- **IN PROGRESS** — partial implementation or verification remains.
- **IMPLEMENTED** — code is present and integrated, but required tests have not all passed.
- **TESTED** — applicable automated/source tests passed; live behavior may still be unverified.
- **VERIFIED** — the stated acceptance criteria passed in the real target environment; scope and date must be recorded.
- **BLOCKED** — a named external permission, credential, account, device, service, or resource is required.
- **NOT APPLICABLE** — technically inapplicable, with a reason recorded.

A row is **not** 100% complete until every applicable automated, integration, security, and manual/live criterion in that row has evidence. Aggregate sector state is the least-complete required criterion, not an average that hides blockers.
