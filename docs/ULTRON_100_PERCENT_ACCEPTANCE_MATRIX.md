## Status vocabulary

Use only these statuses:

- **NOT STARTED** — no implementation evidence identified.
- **IN PROGRESS** — partial implementation or verification remains.
- **IMPLEMENTED** — code is present and integrated, but required tests have not all passed.
- **TESTED** — applicable automated/source tests passed; live behavior may still be unverified.
- **VERIFIED** — the stated acceptance criteria passed in the real target environment; scope and date must be recorded.
- **BLOCKED** — a named external permission, credential, account, device, service, or resource is required.
- **NOT APPLICABLE** — technically inapplicable, with a reason recorded.

A row is **not** 100% complete until every applicable automated, integration, security, and manual/live criterion in that row has evidence. Aggregate sector state is the least-complete required criterion, not an average that hides blockers.

## External dependency risk: pinned World Intelligence source

The optional World Intelligence globe remains pinned to upstream source commit `7be5937fc3e3b10cdfa8d3f833536167268768ad` (package version `0.2.1`); the broad upstream history was not imported.

The original candidate workflow ran a dynamic `npm audit fix --ignore-scripts` after an initial install showed five high advisories. That produced a zero-finding build but did not persist the new lock resolution.

Draft PR #403 replaces that non-reproducible step with a fail-closed dependency patch based on upstream's MIT-licensed security update commit `f69e9bba8befe582fdb3f026c5459b20bcb65802`: it preserves the pinned source code, changes only the Puppeteer/Vite dev dependency ranges and 15 reviewed lock entries, removes the vulnerable nested Zod lock entry, and refuses to patch if the expected pinned manifest or package versions drift. It pins Puppeteer `25.16.0`, Vite `6.4.5`, Chromium BiDi `157.0.8090-0`, and Zod `4.6.7`.

The current-base [PR #403 run 41083617385](https://github.com/ayaanraza2008/ULTRON-AI/actions/runs/41083617385) applied that committed patch before `npm ci`; the clean install and stricter `npm audit --audit-level=moderate` both reported **0 vulnerabilities**, the Vite 6.4.5 build passed, and ULTRON bridge injection passed. Vite 6.4.5 addresses the 6.4.4 `server.fs.deny` query-string bypass (GHSA-8g5g-mxqh-grgj).

**Release condition:** PR #403 remains a draft and is not merged. The deterministic lock is tested on the latest candidate, but it becomes part of the integration candidate only after normal review and an authorized merge. Until then, PR #400's base workflow still uses the older dynamic audit-fix path. Large World Intelligence output chunks (approximately 3.54 MB and 2.77 MB minified in the recorded build) and Node's `punycode` deprecation warning remain maintenance/performance items; they do not fail CI.
